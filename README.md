# Nobel Biocare и Zygoma — макет для согласования

Статический макет страницы стоматологии «Подмосковье».

- Ветка `client-review` публикуется через GitHub Pages.
- Откройте `index.html` через любой статический HTTP-сервер.
- Формы демонстрационные: персональные данные никуда не отправляются.
- Основные изображения включены в `assets/`. Некоторые изображения и шрифты загружаются с сайта клиники и Google Fonts.
- Контакты и ссылки подвала перенесены из исходной страницы седации.
- Макет не предназначен для индексации поисковыми системами.
